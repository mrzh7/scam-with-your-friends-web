First open-source preview of **Scam With Your Friends — Web**, an unofficial browser implementation inspired by the original game.

- React/TypeScript desktop and a procedural Three.js office.
- Seven-day progression, fictional callers, inventory, upgrades, accidents and performance reviews.
- Optional AI text dialogue, separate TTS providers, speech recognition and up to four-player cooperative rooms.
- Google login, verified email registration, D1 saves and configurable administrator authorization.
- Five interface languages, English/Chinese README files and self-hosting instructions for Cloudflare Workers.
- MIT for project-owned code, dependency notices, source/reference provenance, contribution templates and CI.

The maintained online demo requires login; there is no local guest demo. AI, speech, email and hosting may incur provider charges. This is experimental: mobile voice/WebGL support varies, and there is no payment or real-money reward system. It is not affiliated with or endorsed by the original game's creators and does not include their media archive.

Validation: 209 tests, i18n checks, TypeScript and production build passed; dependency audit reported zero known vulnerabilities at preparation time. See docs/RELEASE-CHECKS.md for scope and limitations.
